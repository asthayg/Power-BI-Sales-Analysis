# 📊 Sales Analysis Dashboard | Power BI

**Created by: Astha Singh**

## 📌 Project Overview

This project focuses on analyzing sales data and transforming raw data into meaningful business insights using Microsoft Power BI.

The interactive dashboard helps understand sales performance, profitability, product trends, and regional performance through data visualization.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing products and categories.
- Understand regional sales distribution.
- Track monthly sales trends.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV

## 📈 Dashboard Features

- **Sales Overview:** Total sales, total profit, total orders and quantity.
- **Monthly Trends:** Track sales performance over time.
- **Category Analysis:** Compare sales across product categories.
- **Regional Analysis:** Understand sales distribution by region.
- **Product Analysis:** Identify top-performing products.
- **Interactive Filters:** Explore data using slicers.

## 📂 Dataset

The project uses a sample retail sales dataset containing:

- Order ID
- Order Date
- Region
- Category
- Product
- Quantity
- Unit Price
- Discount
- Sales
- Profit

The included dataset contains 600 synthetic sample records.

## 📊 Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin
- Average Order Value

## 💡 Business Questions

1. Which product category generates the highest sales?
2. Which region performs best?
3. How do sales change month by month?
4. Which products generate the most profit?
5. What is the overall business profitability?
